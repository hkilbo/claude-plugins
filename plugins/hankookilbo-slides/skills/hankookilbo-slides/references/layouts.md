## 템플릿에 없지만 허용되는 배치

원본 17종으로 담기 어려운 내용은 아래 배치를 쓴다. 모두 같은 토큰과 규격을 따른다.

**박스 그리드** — 2×2 또는 1×3. 각 박스는 흰 배경 + `GREEN_LINE` 1pt 테두리, 상단에 `GREEN_DEEP` 채움 헤더 바(높이 0.44″) + 흰 글자 13.5pt Bold, 본문 12pt.

**좌우 2단** — 좌측 코드/도표, 우측 설명 리스트. 각 영역 위에 소제목 15pt Bold + `GREEN_DEEP` 1.25pt 실선.

**코드 블록** — 배경 `F5F7F6`(또는 대비용 `E8F8F6`), 테두리 `GREEN_LINE`, `Courier New` 11pt.

**강조 배너** — `GREEN_DEEP` 채움 + 흰 글자 18~20pt Bold. 결론 장표의 핵심 문장 한 줄에만.

**강조 박스** — `GREEN_PALE` 채움 + `GREEN_LINE` 테두리 + `GREEN_DEEP` 13pt 글자. 인용이나 부연 한 단락.

**판정 배지** — 표 안에서 상태를 표시할 때. 충족/해결은 `GREEN_DEEP` 채움 + 흰 글자, 미확인/보류는 흰 배경 + `RULE` 테두리 + `INK_SOFT` 글자.

## 배치 시 흔한 결함

- 표 아래 요소가 표와 겹친다 → `charts-tables.md` 의 행 높이 계산식을 따른다. `rowH` 는 0.5″ 기본.
- 카드 안 제목 길이에 따라 본문 시작 위치가 카드마다 달라진다 → 제목 아래 오프셋을 고정값으로 둔다.
- 하단 안내문(`y 7.0″`)과 캡션(`y 7.55″`)이 본문과 충돌한다 → 본문은 `y 6.8″` 를 넘기지 않는다.
