# 한국일보 공식 슬라이드

한국일보 사내 보고·기획 문서용 슬라이드 서식. **아래 규격을 그대로 따른다. 임의의 색상·폰트·비율을 새로 만들지 않는다.**

## 0단계: 자산 경로를 먼저 확인한다 — 건너뛰지 않는다

(1단계에서 사용자가 **자유 형식**을 선택했다면 이 단계와 이후 규격은 적용하지 않는다.)

이 스킬의 base directory 는 스킬이 로드될 때 `Base directory for this skill: <경로>` 로 주어진다. **그 경로 + `/assets` 가 자산 폴더다.** 작업 시작 전 실제로 존재하는지 확인한다.

```bash
ls "<base directory>/assets"
# hankookilbo-template.pptx  logo-corner.png  logo-vertical.png
# cover-b-artwork.png  example-build.js  chart-sample.js  verify.py
```

| 파일 | 용도 |
|---|---|
| `hankookilbo-template.pptx` | 공식 템플릿 17종 장표. 발표자 노트에 장표별 작성 규칙 수록 |
| `logo-corner.png` | 본문 장표 우측 상단 로고 (87×130) |
| `logo-vertical.png` | 표지 A · 표지 B · 엔딩 세로 로고 (242×471) |
| `cover-b-artwork.png` | 표지 B 하단 아트워크 — 지구본 + 녹색 블록 (2434×1064) |
| `example-build.js` | **제작의 필수 출발점.** 토큰 · 헬퍼 · 표지 A/B 함수 구현 완료 |
| `chart-sample.js` | 손익표 · 구성비 도넛 · 추이 차트를 실제로 구현한 예제 |
| `verify.py` | 서식 준수 자동 점검기. 외부 의존 없음 |

### 자산을 못 찾으면 멈춘다

`ls` 가 실패하거나 이미지 로드가 안 되면 **거기서 중단하고 사용자에게 알린다.**

**절대 하지 말 것** — 로고 대신 "한국일보" 텍스트를 넣기, 도형(타원 · 사각형)으로 표지를 자체 제작하기, 아트워크 없이 표지 B 를 흉내내기. 이렇게 우회하면 서식이 통째로 깨지고, 실제로 그런 사고가 있었다.

## 순서 — 반드시 이 순서로

### 1단계: 서식과 표지를 확정한다

> **이 절이 서식·표지에 관한 유일한 규정이다.** 문서의 다른 어느 곳에도 "물어라 / 묻지 마라" 규정을 두지 않는다. 다른 절에 나오는 A·B 언급은 전부 규격 설명이며, 이 절의 결론을 바꾸지 않는다. 이 절과 다른 절이 어긋나 보이면 **이 절을 따른다.**

확정할 항목은 **서식**(공식 / 자유)과 **표지**(A / B) 둘이다. 아래 세 단계를 순서대로 한 번 실행하면 두 값과 질문 횟수, 통보 문장이 모두 결정된다.

#### 1-1. 확정 — 사용자가 준 근거만 인정한다

인정하는 근거는 **① 사용자 요청문**, **② 사용자가 질문에 직접 답한 값** 둘뿐이다. 스킬 로드 전에 받은 답도 ②에 포함된다. 에이전트의 추측, 문서 성격 판단("기획안이니 A겠지")은 근거가 아니다.

위에서부터 순서대로 적용한다. 먼저 확정된 값은 아래 행이 덮어쓰지 않는다.

| 순위 | 근거 표현 | 확정값 |
|---|---|---|
| 1 | "바로 만들어줘", "묻지 말고", "알아서" | 서식 = 공식 · 표지 = A |
| 2 | "표지 A", "연녹", "기본 표지" | 표지 = A |
| 2 | "표지 B", "아트워크", "지구본" | 표지 = B |
| 3 | "대외 발표용" | 서식 = 공식 · 표지 = B |
| 4 | "한국일보 서식", "공식 양식", "공식 스타일", "사내 서식", "우리 양식" | 서식 = 공식 |
| 5 | "자유롭게", "공식 서식 말고", "그냥 예쁘게", "자유 형식" | 서식 = 자유 |

**이 표에 없는 표현은 근거가 아니다.** "기획안", "신규 사업 제안", "정기 보고", "보고 자료" 등은 서식·표지를 확정하지 못한다.

서식 = 자유로 확정되면 **표지 항목은 소멸한다.** 표지값이 이미 있었어도 버리고, 표지에 관한 이후 절차 전부(질문·통보)를 건너뛴다.

#### 1-2. 질문 — 미확정으로 남은 항목만 묻는다

1-1을 마친 뒤 미확정으로 남은 항목이 곧 질문 대상이다. **미확정 항목이 없으면 질문하지 않는다. 하나라도 있으면 `AskUserQuestion` 을 한 번 호출해 남은 항목을 전부 담는다.**

스킬 로드 전에 던진 질문은 횟수에 포함하지 않는다. 그 질문에 표지가 없었다면 표지는 미확정이고, 따라서 물어야 한다. **"질문은 이미 했으니 넘어간다"는 판단은 하지 않는다.** 이 스킬에서 가장 자주 발생한 실패가 이 경로다.

| 1-1 결과 | 행동 |
|---|---|
| 서식 확정 · 표지 확정 | 질문 없음 → 2단계 |
| 서식 = 자유 확정 | 질문 없음 → 「자유 형식을 선택했을 때」 |
| 서식 확정(공식) · 표지 미확정 | 표지만 묻는다 |
| 서식 미확정 · 표지 확정 | 서식만 묻는다 |
| 둘 다 미확정 | 한 호출에 둘 다 묻는다. 표지 선택지 설명 앞에 "공식 서식을 선택하신 경우에만 적용됩니다"를 붙이고, 자유 형식을 고르면 표지 답은 버린다 |

**서식 질문 문안**

> 한국일보 공식 스타일로 만들까요?

| 선택지 | 설명 |
|---|---|
| **공식 서식** | A4 가로 · 딥그린 팔레트 · 맑은 고딕 · 로고와 페이지 번호 자동. 사내 보고용 |
| **자유 형식** | 내용에 맞춰 자유롭게 디자인. 사내 공유 문서가 아닐 때 |

**표지 질문 문안** — 「표지 유형」 절 유형표의 **"적합한 문서" 열**을 선택지 설명으로 옮긴다. 선택지 라벨은 `A. 연녹 면형` · `B. 하단 아트워크형` 을 쓴다. 좌표·pt 값 같은 규격 수치는 넣지 않는다.

질문 도구가 오류를 내거나(`AbortError`, 권한 스트림 종료 등) 응답이 오지 않으면 **재시도하지 않는다.** 그 시점의 미확정 항목만 서식 = 공식 · 표지 = A로 채우고 즉시 진행한다. **1-1에서 확정된 값은 유지한다.** 반복 질문은 작업이 멈춘 것처럼 보인다 — 만들어 놓고 고치는 편이 낫다.

#### 1-3. 통보 — 사용자가 고르지 않은 값은 완성 보고에 밝힌다

표지값의 출처가 사용자 선택이 아니면, 아래에서 해당 행 하나를 골라 완성 보고에 포함한다. 조용히 넘어가지 않는다.

| 표지값의 출처 | 통보 문장 |
|---|---|
| 1-1 순위 1 ("알아서 / 바로 / 묻지 말고") | 별도 확인 없이 공식 서식 · 표지 A로 만들었습니다. 표지 B나 다른 형식이 필요하면 말씀해 주세요. |
| 1-1 순위 3 ("대외 발표용") | "대외 발표용"이라 하셔서 표지 B(하단 아트워크형)로 만들었습니다. A형이 필요하면 말씀해 주세요. |
| 1-2 응답 실패 후 기본값 | 확인 절차를 건너뛰고 공식 서식 · 표지 A로 만들었습니다. 표지 B나 다른 형식이 필요하면 말씀해 주세요. |
| 그 외 (사용자가 직접 지정 또는 질문에 답) | 통보하지 않는다 |

출처는 항상 하나다. 1-1은 위에서부터 순서대로 적용해 먼저 확정된 값이 이기므로, 순위 1과 순위 3이 동시에 해당하면 출처는 순위 1이고 통보도 순위 1 문장만 쓴다.

서식 = 자유로 확정된 경우 표지가 소멸했으므로 이 표를 쓰지 않는다. 대신 「자유 형식을 선택했을 때」의 고지만 한다.

### 자유 형식을 선택했을 때

이 스킬의 규격을 적용하지 않는다. 색·폰트·비율을 내용에 맞게 자유롭게 정하고, **다만 완성 후 "공식 서식이 아닙니다" 라고 사용자에게 명시한다.** 로고와 템플릿 자산도 쓰지 않는다. 어중간하게 섞으면 공식 문서로 오해받는다.

이후 단계(2~5단계)는 공식 서식을 선택한 경우의 절차다.

### 표지 유형

**규격 설명이다. 어느 표지를 쓸지는 1단계에서 이미 결정되어 있다.** 이 표의 "적합한 문서" 열은 사용자에게 보여줄 선택지 설명 문구이며, 에이전트가 표지를 스스로 고르는 근거가 아니다.

| 유형 | 설명 | 적합한 문서 |
|---|---|---|
| **A. 연녹 면형** | 좌측 흰 여백 + 우측 연녹 면(`EEF8E0`), 좌측 세로 로고, 제목 30pt 검정을 상·하 실선으로 감쌈 | 내부 보고, BSC, 정기 기획안 |
| **B. 하단 아트워크형** | 흰 배경, 좌상단 작은 세로 로고, 제목 36pt **딥그린**, 하단 60% 에 지구본 아트워크 | 대외 발표, 신규 사업 제안, 표지에 무게를 주고 싶은 문서 |

표지 B 의 정확한 배치 (템플릿 16번 슬라이드 기준):

| 요소 | 위치 · 크기 | 서식 |
|---|---|---|
| 세로 로고 | `x 0.427″ y 0.344″ w 0.698″ h 1.354″` | `logo-vertical.png` — 표지 A 보다 작다 |
| 제목 | `x 0.385″ y 2.146″ w 10.312″ h 0.692″` | 36pt Bold · **`14362D`** |
| 메타 (`부서 ㅣ 이름`) | `x 0.396″ y 2.896″ w 8.949″` | 12.75pt · `3F4A44` |
| 하단 아트워크 | `x 0.031″ y 3.156″ w 11.479″ h 5.021″` | `cover-b-artwork.png` — **누락하면 B 형이 성립하지 않는다** |

표지 B 는 아트워크가 하단 전체를 덮으므로 제목·메타를 상단 1/3 안에 둔다. 아트워크를 다른 이미지로 교체하지 않는다.

두 유형 외의 표지는 만들지 않는다. 사용자가 다른 형태를 원하면 A · B 중 가까운 쪽을 제시하고, 그래도 원하면 규격 이탈임을 알린 뒤 진행한다.

### 2단계: 내용을 먼저 확보한다

조사·자료 수집·수치 확인을 먼저 끝낸다. 장표를 그리기 전에 넣을 내용이 확정되어 있어야 한다.

### 3단계: 장표 유형을 고른다

내용에 맞는 유형을 `references/layouts.md` 에서 고른다. **같은 레이아웃을 반복하지 않는다.** 표 · 박스 그리드 · 좌우 2단 · 코드 블록을 섞는다.

표나 차트가 들어가면 `references/charts-tables.md` 를 먼저 읽는다. 행 높이 · 값 라벨 서식 코드 · 조각 색 배정처럼 **빠뜨리면 바로 결함이 되는 수치**가 정리되어 있다.

### 4단계: 만든다

**pptx** — 두 가지 방법이 있다.

1. **템플릿 편집** (원본 장표 유형과 내용 구조가 맞을 때) — 로고·괘선·차트 서식이 그대로 보존된다.

```bash
python3 -c "import sys,zipfile; zipfile.ZipFile(sys.argv[1]).extractall('unpacked')" <template>
# 구조 작업(복제·삭제·순서)을 먼저, 그 다음 ppt/slides/slideN.xml 내용 교체
# 슬라이드 복제는 pptx 스킬의 add_slide.py 사용
(cd unpacked && rm -f ../out.pptx && zip -Xr ../out.pptx .)
```

2. **pptxgenjs 생성** (내용 구조가 원본과 다를 때 — 대부분 이 경우)

**`assets/example-build.js` 를 작업 폴더로 복사해서 내용만 교체한다.** 토큰과 헬퍼 함수를 처음부터 다시 작성하지 않는다. 이미 구현되어 있는 것들이다.

- 표지: `coverA(제목, 메타)` · `coverB(제목, 메타)`
- 본문: `chrome` `title` `lead` `sectionLabel` `table` `note` `caption` `codeBlock` `divider`

자산 경로는 스크립트가 자기 위치에서 스스로 찾는다. 손으로 고칠 필요가 없다. 다른 폴더에서 실행할 때만 `HK_ASSETS` 로 지정한다.

```bash
cp "<base directory>/assets/example-build.js" ./build.js
# 내용 교체 후
HK_ASSETS="<base directory>/assets" node build.js
```

자산이 없으면 스크립트가 즉시 중단하고 이유를 출력한다. **그 메시지가 나오면 우회하지 말고 사용자에게 알린다.**

**HTML** — 같은 토큰을 CSS 변수로 옮기고 슬라이드 크기를 `1170×827px` 로 고정한다. 로고는 base64 로 심어 단일 파일로 만든다. 구현은 `references/html.md` 참고.

작업 전 `assets/hankookilbo-template.pptx` 의 발표자 노트를 `markitdown` 으로 읽는다. 장표별 작성 규칙이 적혀 있고, 그 규칙이 이 문서보다 우선한다. **단 1단계(서식·표지 확정)는 예외이며, 발표자 노트로 뒤집지 않는다.**

### 5단계: 검수한다 — 생략 금지

```bash
python3 "<base directory>/assets/verify.py" out.pptx
```

캔버스 · 폰트 · 팔레트 · 로고 · 제목 위치 · 구분선 · placeholder 를 기계적으로 점검한다. 외부 스킬에 의존하지 않으므로 어느 환경에서든 돌아간다. **위반이 하나라도 나오면 고치고 다시 돌린다.**

이어서 렌더를 눈으로 확인한다.

```bash
soffice --headless --convert-to pdf out.pptx || \
  python3 "$(ls -d ~/.claude/skills/pptx 2>/dev/null || echo .)/scripts/office/soffice.py" --headless --convert-to pdf out.pptx
pdftoppm -jpeg -r 100 out.pdf slide
```

`pptx` 스킬이 있으면 `scripts/office/validate.py` 와 `soffice.py` 를 함께 쓴다. 없으면 위 명령으로 대체한다. 렌더 이미지를 **실제로 열어서** 텍스트 넘침 · 요소 겹침 · 로고 위치 · 표 괘선 정렬을 본다. 표와 아래 요소가 겹치는 것이 가장 흔한 결함이다.

렌더 도구가 아예 없는 환경이면, **렌더 검증을 못 했다는 사실을 사용자에게 알린다.** 조용히 넘어가지 않는다.

## 작성 규칙

- 본문 장표 배경은 **항상 흰색**. 연녹 면은 표지·간지에만.
- 표 헤더는 반드시 `GREEN_DEEP` 또는 `GREEN` 채움 + 흰 글자 Bold. 첫 열은 가운데 정렬 Bold, 나머지는 좌측 정렬.
- 간지에는 **제목 외 아무것도 넣지 않는다.**
- 목록은 `·` 로 시작한다. 리터럴 `•` 를 쓰지 않는다.
- 수치는 `00.0` / `000%` / `+0.0` 자리표 형식을 따른다.
- 단위는 표 좌상단에 `( 단위 : 억원 )` 형식으로 표기한다.
- 출처는 `자료: ○○○ 집계 · YYYY.MM.DD 기준` 형식으로 하단에 둔다.
- 그라디언트 · 그림자 · 둥근 모서리 강조를 쓰지 않는다. 직선 괘선과 면 채움만으로 구성한다.
- 제목 아래 장식선을 임의로 추가하지 않는다. 규격에 있는 `y 0.96″` 실선만 쓴다.
- 원본에 남아 있는 `○○○`, `00.0`, 빨간 안내문은 **최종본에서 반드시 제거**한다.
- 표 `rowH` 는 0.5″ 기본. 표 하단 = `y + (행 수+1) × rowH + 0.3″` 로 계산해 다음 요소 위치를 정한다.
- 차트 값 라벨에 `dataLabelFormatCode` 를 **반드시 지정**한다. 빠지면 `96.4` 가 `96` 으로 반올림된다.
- 구성비 차트는 조각 안에 값을 넣지 않는다. 우측 목록에 색 칩과 함께 수치를 둔다. (밝은 조각에서 대비가 깨진다)
