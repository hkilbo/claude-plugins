# 한국일보 슬라이드

한국일보 공식 슬라이드 서식으로 보고 자료를 만드는 플러그인입니다. 템플릿 파일과 로고가 함께 들어 있어 별도 준비 없이 바로 쓸 수 있습니다.

## 설치

```bash
/plugin marketplace add hkilbo/claude-plugins
```

```bash
/plugin install hankookilbo-slides@hankookilbo
```

설치 후 **새 세션부터** 스킬이 인식됩니다.

## 무엇을 할 수 있나

**슬라이드 만들기** — "2026년 상반기 사업계획 슬라이드 만들어줘" 처럼 말하면 시작할 때 두 가지를 물어봅니다.

1. 한국일보 공식 스타일로 만들지 (공식 서식 / 자유 형식)
2. 표지 유형 (연녹 면형 / 하단 아트워크형)

공식 서식을 고르면 A4 가로 · 딥그린 팔레트 · 로고 · 페이지 번호가 자동으로 적용됩니다. 자유 형식을 고르면 규격을 적용하지 않고, 결과물이 공식 서식이 아니라는 점을 알려 줍니다. 파워포인트 파일과 브라우저로 보는 HTML 슬라이드 모두 가능합니다.

**질문 없이 한 번에 끝내려면** 요청에 조건을 함께 적으세요. 요청문에 답이 들어 있으면 묻지 않고 바로 만듭니다.

> "한국일보 서식으로 2026년 사업계획 덱 만들어줘"
> "표지 B로 대외 발표 자료 만들어줘"
> "묻지 말고 바로 만들어줘"

**기존 문서 바꾸기** — "이 PPT 공식 서식으로 바꿔줘" 처럼 말하면 외부에서 받은 덱이나 개인이 만든 자료를 사내 보고 형식으로 재편합니다. 색·폰트만 바꾸는 게 아니라 내용을 적절한 장표 유형에 다시 배치합니다.

**서식 점검** — "서식 맞는지 봐줘" 처럼 말하면 캔버스 크기·폰트·색상·로고 위치·텍스트 넘침을 확인하고 어긋난 항목을 슬라이드 번호와 함께 알려 줍니다.

## 서식 요약

- **A4 가로 11.7″ × 8.27″** — 16:9 아닙니다
- 딥그린 `#14362D` 주색, 연녹 `#EEF8E0` 표지·간지 면
- 전 요소 맑은 고딕
- 본문 장표 제목 24.75pt, 우측 상단 로고, 우측 하단 페이지 번호
- 표 헤더는 딥그린 채움 + 흰 글자

## 들어 있는 것

- 공식 템플릿 17종 장표 (표지 2종 · 목차 · 간지 · 손익표 · SWOT · 전략맵 · KPI · 실행과제 · 차트 2종 · 별첨 · 엔딩)
- 로고 이미지 2종 (본문용 · 표지용) + 표지 B 하단 아트워크
- pptxgenjs 예제 스크립트 (표지 A·B 함수 포함)
- 서식 자동 점검기 `verify.py`
- 표 · 차트 구현 예제와 규격 문서

## 알아둘 점

맑은 고딕은 Windows 폰트입니다. Mac에서 열면 다른 폰트로 대체 렌더되어 줄바꿈이 달라질 수 있습니다. 파일 안에는 사내 표준대로 맑은 고딕이 들어갑니다.

## 서식이 개정되면

`skills/hankookilbo-slides/assets/hankookilbo-template.pptx` 를 새 템플릿으로 교체하고, 규격이 바뀌었다면 같은 폴더의 `SKILL.md` 와 `references/layouts.md` 의 수치를 함께 고칩니다.

배포는 버전을 올려서 합니다. 두 곳의 `version` 을 **같은 값으로** 올려야 합니다.

- `plugins/hankookilbo-slides/.claude-plugin/plugin.json`
- 저장소 루트 `.claude-plugin/marketplace.json` 의 `hankookilbo-slides` 항목

검증한 뒤 push 하면 사용자가 `/plugin update` 로 받습니다.

```bash
claude plugin validate .
```

자세한 절차는 저장소 루트의 [CONTRIBUTING.md](../../CONTRIBUTING.md) 를 보세요.
