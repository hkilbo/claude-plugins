# 한국일보 인터랙티브

한국일보 인터랙티브 기사 페이지(Astro + React)를 공식 템플릿으로 만드는 플러그인입니다. 기획 인터뷰부터 프로젝트 생성, 자체 점검, 완료 문서화, 전달용 zip 패키징까지 진행하고, 자주 쓰는 인터랙션에 어떤 라이브러리를 쓸지 정해진 규칙대로 고릅니다. 사내 제작자와 외주 제작사가 같은 플러그인을 씁니다.

## 설치

```bash
/plugin marketplace add hkilbo/claude-plugins
```

```bash
/plugin install hankookilbo-interactives@hankookilbo
```

설치 후 **새 세션부터** 스킬이 인식됩니다.

## 무엇을 할 수 있나

**인터랙티브 페이지 만들기** (`hankookilbo-interactives`) — "인터랙티브 페이지 만들어줘", "이 사진들로 스크롤 스토리 만들어줘" 처럼 말하면 기획 질문부터 시작합니다. 개발 지식이 없어도 질문에 답하면 됩니다.

1. 기획 인터뷰 — 연출 방식(스크롤 여정형, 예전/지금 비교 슬라이더, 타임라인, 지도 경로형, 풀스크린 갤러리), 소재·원고, 메타 정보 확인
2. 공식 템플릿(Astro + React)으로 프로젝트 생성 — 한국일보 필수 스크립트·헤더·바이라인이 포함됩니다
3. 자체 점검 — 필수 식별자 검사, 모바일·태블릿·PC 화면 스크린샷
4. 완료 문서화와 전달용 zip 패키징

**라이브러리 고르기** (`hankookilbo-interactives-libs`) — 캐러셀, 스크롤 인터랙션, 지도, 지도 위 데이터, React 아일랜드 간 상태 공유가 필요할 때 쓸 라이브러리와 붙이는 방법을 정합니다. 라이브러리 없이 CSS·vanilla JS로 충분한 경우도 함께 판단합니다.

## 한국일보 담당자에게 받아야 하는 것

- **기사 키**(`ARTICLE_KEY`, "A"+19자리) — 한국일보 기획팀이 발행합니다. 없으면 임시값으로 만들고 완료 문서에 남깁니다.
- **배포** — 만든 zip을 한국일보 담당자에게 전달하면 한국일보 쪽에서 배포합니다. 제작사가 직접 올리지 않습니다.

## 화면 점검(스크린샷)을 쓰려면

자체 점검의 스크린샷 단계는 Playwright를 씁니다. 만든 프로젝트 폴더에서 처음 한 번만 설치합니다. `--no-save`라 `package.json`은 바뀌지 않습니다.

```bash
npm install playwright --no-save
```

```bash
npx playwright install chromium
```
